
# IPL Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive Power BI dashboard built using IPL (Indian Premier League) data from 2008–2022. The dashboard provides insights into team performance, player statistics, venue analysis, tournament records, and season-wise trends.

The objective of this project is to transform raw IPL match data into meaningful visualizations that help users analyze player performances, team achievements, and tournament statistics.

---

## Tools & Technologies Used

* Power BI
* Power Query
* DAX
* Microsoft Excel / CSV
* Data Visualization

---

## Dataset Information

The project uses two datasets:

1. `ipl_matches_2008_2022.csv`

   * Match details
   * Teams
   * Venues
   * Winners
   * Toss information

2. `ipl_ball_by_ball_2008_2022.csv`

   * Ball-by-ball records
   * Runs scored
   * Wickets
   * Batting and bowling statistics

---

## Dashboard Features

### Tournament Insights

* IPL Title Winner
* Orange Cap Holder
* Purple Cap Holder
* Total Tournament Fours
* Total Tournament Sixes

### Batting Analysis

* Total Runs
* Strike Rate
* Total Fours
* Total Sixes
* Player-wise filtering

### Bowling Analysis

* Total Wickets
* Economy Rate
* Bowling Average
* Bowling Strike Rate
* Bowler-wise filtering

### Team Analysis

* Season-wise team performance
* Total wins by team
* Team comparison

### Venue Analysis

* Match results by venue
* Runs, wickets, and super-over statistics
* Stadium-wise performance insights

---

## Key Insights

* Virat Kohli emerged as the highest run scorer with 6634 runs.
* Sandeep Sharma was among the leading wicket-takers.
* Mumbai Indians recorded the highest number of wins.
* Eden Gardens and Wankhede Stadium hosted the highest number of matches.
* Team performances can be analyzed season-wise using interactive filters.
